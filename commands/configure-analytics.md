# Configure Analytics

Interactive wizard for CRM Analytics + Data Cloud setup.

## Steps

1. PSL: `CRM Analytics Plus and Manufacturing Analytics Apps`.
2. Setup → CRM Analytics Studio → Create app → Analytics for Automotive template.
3. Refresh dataflows to populate dashboards.
4. (Optional) Stand up Data Cloud + install the **Automotive data kit** to populate calculated insights and data streams.
5. Embed dashboards on Account / Vehicle / Asset record pages.
6. Verify Forecasting setup if needed:
   - Manufacturing Sales Agreements Psl
   - Manufacturing Advanced Account Forecast Psl
   - Manufacturing Account Manager Targets Psl
   - Program Based Business Psl for Manufacturing Cloud
