# Configure Partner Visits

Interactive wizard for Partner Visit Management.

## Steps

1. PSLs: `Partner Visit Management`, `Action Plans`, `Industries Visit`.
2. Setup → Partner Visit Management → Enable Partner Visit Management.
3. Mark **Partner Visits** app Visible on profiles.
4. Configure Action Plan Templates with Generic Visit Tasks.
5. Define Generic Visit Task Contexts and Generic Visit Task Context Relations (M:M).
6. Define Assessment Indicator Definitions and Generic Visit KPIs.
7. (Experience Cloud) PSL: `Partner Visit Management for Experience Cloud`.
8. Configure Visit and Task page layouts (separate layouts for sales managers vs. evaluation officers).
