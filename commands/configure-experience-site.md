# Configure Experience Cloud Site

Interactive wizard for partner / customer portals.

## Steps

1. Setup → Digital Experiences → Enable Digital Experiences.
2. Create site using the **Automotive template**.
3. Create partner / customer user profiles.
4. Assign external PSLs (mandatory `Automotive Foundation for Experience Cloud` + feature PSLs based on persona — see `auto-experience-cloud` skill).
5. Configure sharing sets per object the external user should access.
6. Customize the site to surface only the features that persona needs.
7. Test as the external user (not internal admin) to verify visibility.
