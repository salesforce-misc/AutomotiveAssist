# Configure Connected Services

Interactive wizard for telematics + remote actions.

## Steps

1. PSL stack: `Vehicle Connected Services`, `Service Process Studio`, `Context Service Admin`, `Context Service Runtime`, `Omnistudio`, `Omnistudio User`, `MuleSoft Anypoint Platform`, `Business Rules Engine Designer`, `Business Rules Engine Runtime`.
2. Confirm Automotive is enabled.
3. Setup → Connected Services → Vehicle Connected Services Settings → Enable Vehicle Connected Services. Accept terms.
4. Enable Predefined Components for Connected Vehicle Services.
5. Configure predefined service processes: Remote Vehicle Door Lock and Unlock, Remote Vehicle Notifications and Alerts.
6. (For AEO) PSLs: `Actionable Event Orchestration Designer`, `Actionable Event Orchestration Runtime`.
7. Define Actionable Event Types / Subtypes / Orchestrations + Expression Sets.
8. Define Telemetry Definitions / Telemetry Action Definitions for bulk remote ops.
9. Configure eligibility rules per service process.
