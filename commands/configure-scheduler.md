# Configure Scheduler

Interactive wizard for test drive + vehicle service appointment scheduling.

## Steps

1. PSLs: `Automotive Scheduler`, `Salesforce Scheduler`, `OmniStudio User`.
2. Setup → Automotive Settings → Enable Automotive Scheduler.
3. Setup → Omnistudio Settings → Enable Standard Omnistudio Runtime.
4. Setup → Salesforce Scheduler Settings → Enable Multi-Resource Scheduling.
5. Setup → Salesforce Scheduler Settings → Enable Operating Hours for Service Territory Members for Work Type Groups.
6. Configure Service Resources, Service Territories, Work Types, Work Type Groups, Operating Hours.
7. Verify Lead and Opportunity layouts have Schedule Test Drive button (and default Schedule Appointment removed).
