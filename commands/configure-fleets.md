# Configure Fleets

Interactive wizard for the Fleet Management journey.

## Steps

1. Verify `Fleet Management` PSL assignment.
2. Setup → Fleet Management Settings → Enable Fleet Management.
3. Walk through Fleet records (commercial fleet groupings).
4. Configure Fleet Asset junction records.
5. Configure Fleet Participant junction (fleet manager, drivers).
6. (Experience Cloud) verify `Fleet Management for Experience Cloud` PSL for external fleet managers.
