# Configure Service Console

Interactive wizard for the Service Console for Automotive.

## Steps

1. PSLs: `Industry Service Excellence` + `Automotive Foundation User`.
2. Setup → Service Console for Automotive → Enable. (Also enables predefined Identity Verification flows.)
3. **Confirm with user before enabling Lightning Knowledge** — this is one-way.
4. Setup → Knowledge Settings → Edit → Enable Lightning Knowledge. Requires ≥1 article type already created.
5. (For Knowledge Manager users) PSL: `Service Lightning Knowledge Manager`.
6. Mark **Service Console for Automotive** app Visible on relevant profiles.
7. Customize Account / Asset / Vehicle / Financial Account / Case page layouts to surface predefined components.
