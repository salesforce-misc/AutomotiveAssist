# Configure Inventory

Interactive wizard for vehicle inventory search.

## Steps

1. Confirm Automotive is enabled (prerequisite for the DPE template).
2. PSLs: `Criteria-Based Search and Filter`, `Data Pipelines Add On User Settings`, `Data Pipelines Base User`.
3. Setup → Criteria-Based Search and Filter → Enable.
4. Setup → Data Pipelines → Get Started → Enable Data Pipelines.
5. Configure Vehicle Searchable Field records.
6. Run the **Update Vehicle Searchable Field Values** Data Processing Engine template.
7. Setup → Inventory Settings → Enable Visit Inventory Management (if reps record samples / parts on visits).
8. (Experience Cloud) PSL: `Criteria Based Search and Filter for Experience Cloud`.
