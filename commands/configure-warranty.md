# Configure Warranty

Interactive wizard for the warranty + claims stack.

## Steps

1. PSLs: `Warranty Lifecycle Management Psl`, `Claims Management Foundation`.
2. Setup → Warranty Lifecycle Management → Enable.
3. Configure Code Set + Codeset Relationship records.
4. Define Product Fault Code + Product Labor Code records.
5. Define Warranty Term records → Product Warranty Term + Asset Warranty.
6. Define Warranty Term Coverage rules (per Code Set / part).
7. Configure Claim model (Claim, Claim Item, Claim Coverage, Claim Coverage Payment Detail, Claim Participant).
8. (Supplier Recovery) configure Supplier, Supplier Product, Contract, Sales Contract Line.
9. (Experience Cloud) PSLs: `Warranty Management For Experience Cloud`, `Warranty Supplier Recovery for Experience Cloud`.
10. Mark **Warranty Lifecycle Management** app Visible on profiles that need it.
