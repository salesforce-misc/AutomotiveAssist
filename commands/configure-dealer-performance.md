# Configure Dealer Performance

Interactive wizard for Partner Performance Management.

## Steps

1. PSLs: `Partner Performance Management` (internal), `Partner Performance Management for Experience Cloud` (external).
2. Setup → Partner Performance Management → Enable.
3. Configure Rebate Claim and Transaction Journal page layouts.
4. (Optional) Add Rebate Management add-on for incentive payouts.
5. Configure Sales Agreements, Account Manager Targets, Manufacturing Programs as needed.
6. Verify OWD: Rebate Claim = Private; Sales Agreement = Public Read/Write internal, Private external.
