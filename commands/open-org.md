# Open Org

Open the connected Automotive Cloud Salesforce org in the browser.

$ARGUMENTS

## Steps

1. If a path was provided in arguments → call `open_org` with that path.
2. If no path → open to the default home page.
3. Common useful paths:
   - `/lightning/o/Automotive` — the Automotive app
   - `/lightning/setup/SetupOneHome/home` — Setup home
   - `/lightning/n/Service_Console_for_Automotive` — Service Console
   - `/lightning/n/Partner_Visits` — Partner Visits app
