Explore, set up and configure, and monitor usage of Automotive Cloud features in one streamlined setup
location. Access content resources, such as videos, online tours, Trailhead, and Salesforce Help articles,

more Automotive Cloud features and add-on licenses that are available based on your Salesforce edition.

directly from Salesforce Go.

**REQUIRED EDITIONS**


Available in: Lightning Experience

Available in: Enterprise and Unlimited Editions


1. Select Salesforce Go from the gear menu or from the main Setup menu.
2. The search feature in Salesforce Go suggests feature names that are similar to the search term you
enter. You can search for any feature within Automotive, such as Vehicle or Asset Lending or
Connected Vehicles.
3. Go to the Feature Sets tab and set the filter for Automotive.
4. You can find the list of feature sets included under Automotive that you can set up using Salesforce
Go.
5. Click Keep Going on a feature set and follow the guided prompts to complete the setup.
To learn more about Salesforce Go, see Discover and Set Up Features with Salesforce Go.
