# Vehicle Connected Services

MuleSoft + telemetry integration; Actionable Event Orchestration for inbound vehicle events (DTCs, engine/transmission alerts); Remote Vehicle Door Lock/Unlock and Remote Notifications service processes; eligibility rules.

## Primary objects / settings

`Service Process` definitions, `Actionable Event Type / Subtype / Orchestration`, `Expression Sets`, `Vehicle Connected Services` PSL, MuleSoft Anypoint Platform PSL.

## Setup-sequence position

Steps 29-30 — Vehicle Connected Services (Service Process Studio + Context Service + Omnistudio + MuleSoft) → Actionable Event Orchestration (Designer + Runtime PSLs).

## Prerequisites

Service Process Studio, Context Service Admin/Runtime, Omnistudio Runtime, and MuleSoft Anypoint Platform PSLs must all be assigned before connected services light up.
